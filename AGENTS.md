# SoundCity project preferences

- Use black, graphite and midnight surfaces with orange accents for the default dark theme; avoid light backgrounds and teal/green branding.
- Dial and slider gain indicators use a green → amber → red gradient in both directions away from zero, reaching red at the strongest cut or boost. This is a control indicator, while the surrounding branding remains orange and dark.
- Make the desktop UI polished and purposeful: clear hierarchy, generous spacing, readable contrast, coherent controls, and useful device status.
- Keep this visual style consistent across future SoundCity UI work.
- Device controls must reflect actual supported hardware. Do not substitute a similarly named device's protocol without evidence, or present simulated values as live data.
