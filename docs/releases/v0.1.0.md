SoundCity's first public Windows release brings headphone controls, a dark graphite
and orange interface, and an equaliser with interchangeable dials and sliders.

## Download

- **SoundCity-0.1.0-Setup-x64.exe** — recommended installer. Installs for your
  Windows account, adds a Start menu shortcut, and supports uninstalling from
  Windows Settings. A desktop shortcut is optional.
- **SoundCity-0.1.0-Portable-x64.zip** — extract into a folder and run `SoundCity.exe`.
- **SHA256SUMS.txt** — checksums for both downloads.

Requires Windows 10 version 2004 or newer, or Windows 11, with x64 support.
The .NET 10 LTS runtime is included. No separate runtime installation or
administrator access is required. This release is not code-signed, so Windows
may display an unknown-publisher or SmartScreen warning.

## Included

- Soundcore Liberty 4 Pro and Life P3 controls through OpenSCQ30.
- Native Studio Max5s controls and experimental Parrot Zik 3 support.
- Windows volume/mute for supported headphone outputs, including FitBuds,
  Beats Solo Buds and AirPods Pro 3.
- Ten-band Windows EQ and optional volume boost through Equalizer APO.
- Matching green → amber → red dials and sliders, mouse-wheel adjustment,
  numeric gain entry, saved profiles and remembered control views.
- Original SoundCity icon and dark menus, dialogs and installer.

## Setup and limitations

Pair headphones in Windows, open SoundCity, and select your device. For renamed
headphones use **Identify headphones**. Changes take effect when you press Apply.

Windows EQ and boost require a separate Equalizer APO installation configured for
the intended output. This installer does not install APO, change audio settings,
raise volume or install Bluetooth/Apple drivers. Saved profiles and APO
configuration are preserved when SoundCity is uninstalled.

FitBuds vendor controls and advanced AirPods/Beats controls are not integrated.
Parrot Zik 3 remains experimental, and physical validation of several model-specific
writes is still pending. See the [device support table](https://github.com/GoblinRules/SoundCity/blob/v0.1.0/README.md#device-support)
for the exact supported features and validation limits.

The release includes licenses and OpenSCQ30 corresponding source. SoundCity source
is available in the automatic source archives below and at tag `v0.1.0`.

Validation: all 142 core/backend checks and 29 UI checks passed on .NET 10. Fresh
installation, reinstallation, installed app launch in demo mode, Start menu
shortcut and uninstall were checked. All 484 installed files match the portable
payload; existing audio configuration and preferences remained unchanged.
